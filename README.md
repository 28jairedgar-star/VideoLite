# VideoLite

Editor Android ligero, pensado para trabajar directamente desde el teléfono.

## Estado
Primera base del proyecto: selector de videos, vista previa y estructura visual inicial del editor. Las herramientas de edición se incorporarán progresivamente.

## Compilar sin Android Studio
Cada push a `main` ejecuta GitHub Actions y genera un APK de depuración. También se puede iniciar manualmente desde **Actions → Build Android APK → Run workflow**.

El APK queda disponible como artefacto descargable en la ejecución del workflow.
